# 旅管词典

面向高校旅游与酒店管理专业学生的静态术语速查网站，可直接通过 GitHub Pages 部署。

## 功能

- 内置 36 个术语，覆盖旅游管理、酒店运营、餐饮管理、市场营销、行业基础和旅行服务
- 支持按名称、类别和解释实时搜索，并可组合类别筛选
- 点击术语卡片查看完整解释，无结果时可一键重置
- 响应式布局，适配电脑与手机；支持 `Ctrl/Command + K` 聚焦搜索

## 本地使用

项目不需要安装依赖或构建。可直接打开 `index.html`，也可以在项目目录运行：

```bash
python3 -m http.server 8000
```

随后访问 `http://localhost:8000/`。

## GitHub Pages 部署准备

首页为根目录的 `index.html`，所有资源均使用相对路径，适合仓库子路径部署。在仓库 **Settings → Pages** 中，将发布源设置为目标分支的根目录（`/ root`）即可；无需构建命令或 GitHub Actions。

## 项目结构

```text
.
├── index.html   # 页面结构
├── styles.css   # 视觉与响应式样式
├── app.js       # 术语数据、搜索、筛选与详情交互
└── README.md    # 项目说明
```

网站内容用于教学辅助。实际行业操作及指标口径请以所在机构规范与课程要求为准。
